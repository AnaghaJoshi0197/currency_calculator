# 💱 Global Currency Converter Dashboard

A professional real-time currency converter built with Python and Streamlit. This application connects to live financial APIs to provide accurate exchange rates for over 160 global currencies.

## 🚀 Live Demo
[**Click here to view the App**] 

## ✨ Features
*   **Real-Time Data:** Fetches live exchange rates via API.
*   **Historical Analysis:** Interactive line charts showing 1-year performance trends using Pandas.
*   **Smart Dashboard:** A split-screen layout separating controls from data visualization.
*   **Dual-Direction:** Convert any currency to any other currency (Any-to-Any).

## 🛠️ Tech Stack
*   **Python 3.10+**
*   **Streamlit** (Frontend UI)
*   **Pandas** (Data Visualization)
*   **Requests** (API Handling)
